## Revision 1 — current prototype

Hardware and software are about 90% complete. This revision uses hand wiring on a Perma-Proto board, and the shell has not been made yet.

- [x] Assemble the prototype hardware.
- [x] Develop the prototype software (builder-reported; source not uploaded yet).
- [x] Record the supplied wiring assignments and select build photos.
- [ ] Finish the remaining hardware and software work.
- [ ] Confirm the outstanding details in the [pinout](pinout.md#details-still-to-confirm).
- [ ] Make and fit the enclosure.
- [ ] Add the existing firmware, dependencies, control guide, and setup instructions.
- [ ] Record battery runtime, charging behavior, and basic audio checks.

## Future revisions — hoped-for releases

- [ ] Design and test a custom PCB.
- [ ] Release PCB source and fabrication files after verification.
- [ ] Design and test a 3D printable case.
- [ ] Release enclosure source and print files after checking fit and assembly.

These are intentions, not completed releases or promised dates. Rev 1 remains the documented prototype until a later revision is ready.
